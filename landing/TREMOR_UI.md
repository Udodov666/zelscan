# Tremor UI source

The admin visual layer uses the official light-theme system and block compositions from Tremor:

- Blocks source: https://github.com/tremorlabs/tremor-blocks
- Open-source dashboard reference: https://github.com/tremorlabs/template-dashboard-oss
- Blocks browser: https://blocks.tremor.so/blocks
- Setup: https://blocks.tremor.so/getting-started

Implemented compositions: Page Shell, Login, KPI Cards, Status Monitoring / Tracker, Chart Composition, Filterbar, Tables, Table Actions, Badges, Dialogs, Empty States, Billing & Usage, and Account/User Management.

The default white/gray/blue Tremor design tokens are retained. Only product text and data bindings are replaced with Zelscan content. Existing API routes and report URLs remain unchanged.
