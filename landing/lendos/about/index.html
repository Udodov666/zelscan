01 / Назначение

Что делает Zelscan

Zelscan анализирует доступные данные профиля на lolz.team: публикации, активность и особенности общения. На их основе сервис формирует психологический портрет аккаунта.

Результат относится к поведению конкретного профиля внутри форума. Он не содержит сведений о том, кто владеет аккаунтом в реальной жизни.

02 / Данные

Какие данные используются

Источник
lolz.team

Результат
Интерпретация поведения и стиля общения профиля

03 / Техника

Как мы работаем с API

Полная техническая картина: что сервис собирает через официальный API, как обрабатывает данные и какая нагрузка приходится на форум.

Метод
Официальный API lolzteam: Bearer-токены, эндпоинт поиска /search/posts и профильные запросы. HTML-страницы не скрейпятся.
Вид данных
Только публичные сообщения пользователя (темы и стена профиля) и публичный профиль.
Объём на досье
До 700 последних публичных сообщений.
Запросов на досье
Около 90: ≈9 POST + ≈72 GET, суммарно ~25 секунд.
Частота
Один заказ = одна сессия сбора. Повторные просмотры отчёта идут из кэша, без запросов к форуму.
Хранение
Собранные сообщения лежат в закрытом хранилище сервиса и используются только для расчёта метрик досье.

03Досье

Итоговый отчёт

Из метрик складываются разделы досье: индекс доверия, архетипы общения, эмоциональный фон, триггеры, признание ошибок и эмпатия, поведенческие паттерны.

Один заказ одновременно

Заказы выстраиваются в очередь и обрабатываются строго по одному: пока идёт сбор по первому, остальные ждут. Форум нагружает один последовательный поток, а не пул параллельных парсеров.

Токены и лимиты

У API лимит на каждый токен: POST /search/posts — 30 запросов в минуту, GET — 300. У сервиса пять токенов: три работают на сбор сообщений, отдельный — на поиск и топы, ещё один — на профили.

3 токена

Сбор сообщений

Каждое новое поисковое окно создаётся на следующем токене по кругу — нагрузка 30/мин делится ровно.

1 токен

Поиск и топы

Поиск, топы, аватары и проверки доступности. Лёгкие запросы не конкурируют со сбором сообщений.

1 токен

Профили

Публичная карточка пользователя: статистика, статус, дата регистрации.

  • Бюджеты считаются из заголовков X-RateLimit-Remaining (резерв 2 запроса) — токен с исчерпанным бюджетом пропускается.
  • Пагинация окна никогда не переезжает на другой токен: курсор поиска привязан к токену, который создал окно.
  • Ответ 429 — пауза строго по Retry-After, повтор с другим токеном.
  • Ротация существует, чтобы укладываться в лимиты, а не обходить их.

Цифры — из реального прогона. Лог телеметрии сохраняется для каждого сбора и предоставляется администрации по запросу.

04 / Ограничения

Чего сервис не делает

  • Не использует сторонние OSINT-сервисы и базы утечек.
  • Не ищет имя, фамилию, дату рождения, адрес или местоположение владельца.
  • Не ищет телефон, электронную почту, соцсети и аккаунты на других площадках.
  • Не сопоставляет профиль с реальным человеком.
  • Не предназначен для деанонимизации пользователей.
  • Не читает личные сообщения и содержимое разделов под хайдами.
  • Не публикует и не передаёт собранные сообщения третьим лицам.
  • Не хранит API-токены в коде или репозитории.

05 / Отчёт

Как трактовать результат

01

Это не диагноз

Психологический портрет — вероятностная интерпретация текстов и поведения аккаунта, а не медицинское заключение.

02

Возможна ошибка

На выводы влияют сарказм, ролевая манера общения, неполная история и контекст отдельных обсуждений.

03

Нужна проверка

Для решений модерации следует смотреть исходные публикации. Отчёт не является самостоятельным доказательством нарушения.

06 / Вопросы

Короткие ответы

Это OSINT-сервис?

Нет в смысле поиска личности по внешним источникам. Zelscan работает с данными профиля внутри lolz.team и не подключает сторонние OSINT-инструменты.

Можно узнать, кто стоит за ником?

Нет. Сервис не устанавливает реальную личность владельца аккаунта.

Откуда берутся данные?

Из доступного профиля пользователя на lolz.team: тем, постов, сообщений, активности и форумной статистики.

Можно принимать решение только по отчёту?

Нет. Отчёт помогает быстрее оценить профиль, но решение следует проверять по исходным публикациям и правилам форума.

Сколько запросов к форуму занимает один отчёт?

Около 90: девять поисковых окон и примерно 72 страницы результатов, суммарно ~25 секунд. Телеметрия каждого запроса сохраняется.

Почему у сервиса несколько API-токенов?

У API есть лимит на токен — 30 поисковых запросов в минуту. Три токена сбора позволяют укладываться в лимиты при одном одновременном заказе: нагрузка распределяется по кругу равномерно.

Zelscan связан с lolz.team?

Zelscan — отдельный сервис. Эта страница описывает его назначение и не означает официального одобрения со стороны администрации форума.

Если модерации нужна дополнительная информация о работе сервиса — включая полный лог запросов любого сбора — можно связаться с автором проекта.
