Первоначальная настройка Zelscan Local

Ключи хранятся только на вашем компьютере и никуда не отправляются.

Где взять: lolz.team → Настройки → API → создать токен с правами на чтение профиля и поиска. Рекомендуется 1–3 токена.
Создайте своё приложение на форуме: lolz.team → Настройки → Разработчикам → Создать приложение:
  1. Название — любое, например Zelscan Local
  2. Redirect URI — http://localhost:8080/oauth/callback (скопируйте точно)
  3. Разрешённые домены — введите * (звёздочка)
  4. Создайте и вставьте сюда Client ID
