# Zelscan Local

Локальная версия [Zelscan](https://zelscan.xyz) — сервиса, который по публичной
активности профиля на форуме lolz.team собирает досье: активность, поведение,
стиль общения, психологический портрет аккаунта.

В этой версии всё бесплатно, всё работает на вашем компьютере и ваши ключи
никуда не отправляются.

## Возможности

- **Ручной режим** — вы вводите ник, статистику и сообщения пользователя сами
  (по одному в строке), сервис собирает полное досье. Форум не запрашивается
  ни разу, токены не нужны.
- **Автосбор** — досье собирается через официальный API lolz.team по вашему
  API-токену. Внимание: правило форума 2.28 запрещает парсинг без разрешения
  администрации. Автосбор включайте, только если у вас есть разрешение или вы
  готовы сами отвечать за соблюдение правил.
- **AI-анализ** (для полного тарифа) — через ваши ключи AKI.IO / OpenRouter.
- Витрина готовых досье, публичные ссылки, отчёты по разделам.
- Админ-панель открыта: любой авторизованный пользователь — полный админ.

## Установка

```bash
git clone <repo>
cd zelscan-local
pip install -r requirements.txt
python app/server.py        # backend на http://localhost:5050
python app/front_server.py  # frontend на http://localhost:8080
```

Откройте `http://localhost:8080` — запустится мастер первоначальной настройки.

## Мастер настройки

1. **Режим**: «Ручной» (токены не нужны) или «Автосбор».
2. **Ключи AI** (опционально, нужны только для AI-анализа):
   - **AKI.IO** — aki.io → API keys;
   - **OpenRouter** — openrouter.ai → Keys (free-модели).
3. **Вход через форум (OAuth)** — обязателен:
   - lolz.team → Настройки → Разработчикам → Создать приложение;
   - Название: любое (например, `Zelscan Local`);
   - Redirect URI: `http://localhost:8080/oauth/callback`;
   - Разрешённые домены: `*` (звёздочка);
   - Вставьте полученный `Client ID` в мастер.
4. Готово — входите через форум и пользуетесь.

## Где что лежит

- `app/` — backend (Flask) + фронт-сервер
- `landing/` — страницы приложения и лендинг
- `scripts/` — анализатор (lolz_analyzer) и AI-интерпретатор
- `cache/results/` — готовые отчёты (в комплекте — примеры)
- `zelscan.db` — заказы, пользователи, история

## Дисклеймер

Инструмент предназначен для анализа публичных данных и обучения. Автоматический
сбор данных форума регулируется правилом 2.28 lolz.team: разрешение выдаётся
администрацией персонально на конкретный вид и объём. Используя автосбор, вы
сами отвечаете за соблюдение правил форума. AI-выводы — вероятностная
интерпретация текстов, а не медицинское заключение.
